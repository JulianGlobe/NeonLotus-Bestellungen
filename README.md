# Neon Lotus – Bestellseite (Preview)

## Öffnen
`index.html` im Browser öffnen.

## Enthalten
- Neon-Lotus-Design mit Logo
- Kategorien Essen / Getränke
- Alle 7 Produkte und Preise
- Mengenwahl und dynamischer Warenkorb
- Abholung / Lieferung
- Liefer-PLZ, Ansprechpartner und optionale Anmerkung
- Responsive Darstellung für Handy / QR-Code-Nutzung
- Vorschau des Bestellabschlusses

## Discord-Anbindung
Die Vorschau erzeugt noch kein echtes Discord-Ticket. Dafür wird im nächsten Schritt ein kleines Backend / Custom Bot ergänzt.
Discord-Bot-Token und andere Geheimnisse dürfen nicht im Frontend (`app.js`) stehen.

Geplante Ticket-Aktionen:
- Bestellung annehmen
- In Zubereitung
- Bereit
- Ausgeliefert / Abgeholt
- Ticket schließen
