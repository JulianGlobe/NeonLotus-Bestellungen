EXAKTER NEON-LOTUS RANG-SYNC

Die Synchronisierung verwendet jetzt eine feste 1:1-Zuordnung:

Hauptdiscord          -> Neon-Lotus-Discord
NL. Nachwuchs         -> Nachwuchs
NL. Clubkraft         -> Clubkraft
NL. Profi             -> Profi
NL. Manager           -> Manager
NL. Leitung           -> Leitung

Bei jeder zentralen Rangänderung auf einen NL.-Rang:
1. Hauptdiscord-Rang wird gesetzt.
2. Bot liest den tatsächlich sichtbaren NL.-Rang auf dem Hauptdiscord erneut ein.
3. Alle anderen Neon-Lotus-Ränge auf dem Neon-Lotus-Discord werden entfernt.
4. Exakt der zugehörige Gegenrang wird gesetzt.
5. Der Bot lädt den Member neu und prüft, ob die Rolle wirklich vorhanden ist.
6. Falls Discord die Rolle nicht setzen konnte, wird jetzt ein Fehler ausgegeben statt still weiterzulaufen.

Die Sakura-Mitarbeiter/Führungs-/Leitungsspiegelung bleibt zusätzlich bestehen.
